# One shared brain for universal games

> **Document control:** ADR-001 · Accepted · Custodian: Repository maintainer

**Decision source:** User-fixed design decisions recorded in ARC-004, section
2, on 2026-10-11. This record transcribes that decision; it is not a new
approval.

## Context

The project is extending its agent from Minecraft to additional games. Separate
per-game policies or world models would weaken the stated aim of testing one
agent across environments and make transfer claims ambiguous.

## Decision

Use one shared policy and world model for supported games. Game adapters may
translate each engine's observations and actions into the shared interface,
but must not introduce a per-game policy or world model. The agent receives
player-facing observations and actions; simultaneous streams remain part of
the shared input as specified in [ARC-004](../architecture/arc-004-universal-games.md).

## Consequences and limits

The adapter boundary must preserve comparable player-facing information and
avoid leaking privileged engine state into learning. A shared implementation
does not establish cross-game behavioral competence. That claim remains
unverified until the evidence gates in ARC-004 are met; see the
[claims register](../governance/gov-005-claims-evidence-register.md).

## Alternatives recorded in the source design

Per-game policies and per-game world models were rejected because they would
not test the shared-agent objective. The source design is authoritative for
the detailed rationale.
